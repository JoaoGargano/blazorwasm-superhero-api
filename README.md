# BlazorWasmSuperHeroApi

Aplicação desenvolvida em **Blazor WebAssembly** (.NET 10) para consulta e exibição de dados de personagens utilizando a SuperHero API com autenticação via token.

### Funcionalidades:
- Mapeamento completo dos modelos de dados em C# (DTOs).
- Consulta assíncrona com `HttpClient` utilizando o endpoint da API (`api.php/{token}/search/{termo}`).
- Interface em cards responsivos com Bootstrap exibindo atributos, informações biográficas e imagem.
